# Installer SPL Gestion de Suivi comme application — gratuit

SPL Gestion de Suivi est une **PWA** (Progressive Web App). Elle s’installe
directement depuis le navigateur, sans payer Google Play ou l’App Store.

## Android (Chrome)

1. Ouvrez l’adresse permanente du site dans Google Chrome.
2. Appuyez sur le bouton **Installer** dans le header du site.
3. Confirmez « Installer ».
4. L’icône SPL apparaît sur l’écran d’accueil et dans la liste des applications.

Si le bouton automatique n’apparaît pas : menu Chrome **⋮** →
**Installer l’application** ou **Ajouter à l’écran d’accueil**.

## iPhone / iPad (Safari)

1. Ouvrez obligatoirement le site dans **Safari**.
2. Appuyez sur **Partager** (carré avec une flèche vers le haut).
3. Faites défiler puis sélectionnez **Sur l’écran d’accueil**.
4. Appuyez sur **Ajouter**.

L’application apparaît avec l’icône SPL et s’ouvre sans barre de navigateur.

## Ordinateur (Chrome / Edge)

1. Ouvrez le site.
2. Cliquez sur **Installer** dans le header ou sur l’icône d’installation à droite de la barre d’adresse.
3. Confirmez.

## Coût

- Installation PWA : **gratuite**.
- Pas de commission de magasin d’applications.
- Pas de compte développeur Apple ou Google nécessaire.
- L’hébergement Vercel et Neon peut commencer avec leurs offres gratuites.
- Seul le nom de domaine personnalisé coûte généralement 10 à 20 € par an.

## Limites

- L’application a besoin d’Internet pour enregistrer et synchroniser les données PostgreSQL.
- Les images et éléments déjà visités disposent d’un cache de secours.
- La publication dans les boutiques App Store / Google Play est une procédure différente et peut être payante.
